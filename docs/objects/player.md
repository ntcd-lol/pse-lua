## Игрок

Команды управления игроком.

### Основной объект:

```lua
PSE.player
```

## Позиция

### `PSE.player:setPosition(x, y, z)`

Установка позиции игрока

```lua
PSE.player:setPosition(0, 0, 10)
```

|Аргумент|Обозначение                |Пример|
|--------|---------------------------|------|
|  `x`   |Координата X (Вперед/Назад)| `0`  |
|  `y`   |Координата Y (Лево/Право)* | `0`  |
|  `z`   |Координата Z (Вверх/Вниз)* | `10` |

### `PSE.player:getPosition()`

Получение позиции игрока

```lua
local pos = PSE.player:getPosition() --- {x, y, z}
```

|Поле |Обозначение                |Пример|
|-----|---------------------------|------|
| `x` |Координата X (Вперед/Назад)| `0`  |
| `y` |Координата Y (Лево/Право)* | `0`  |
| `z` |Координата Z (Вверх/Вниз)* | `10` |

## Вращение

> [!WARNING]
> MOCK-режим НЕ ОБНОВЛЯЕТ поворот игрока и объектов.

### `PSE.player:setRotation(x, y, z, w)`

Установка поворота игрока (низкоуровневый метод).

> [!TIP]
> Это сложный метод вращения на базе кватерниона, лучше используйте [PSE.player:setDegree(pitch, yaw, roll)](#pseplayersetdegreepitch-yaw-roll).

```lua
PSE.player:setRotation(0, 0, 0, 1)
```

|Аргумент|Обозначение                  |Пример|
|--------|-----------------------------|------|
|  `x`   |Векторная часть кватерниона X| `0`  |
|  `y`   |Векторная часть кватерниона Y| `0`  |
|  `z`   |Векторная часть кватерниона Z| `0`  |
|  `w`   | Склярная часть кватерниона  | `1`  |

### `PSE.player:getRotation()`

Получение поворота игрока (низкоуровневый метод).

> [!TIP]
> Это сложный метод вращения на базе кватерниона, лучше используйте [PSE.player:getDegree()](#pseplayergetdegree).

```lua
local rot = PSE.player:getRotation() --- {x, y, z, w}
```

|Поле |Обозначение                  |Пример|
|-----|-----------------------------|------|
| `x` |Векторная часть кватерниона X| `0`  |
| `y` |Векторная часть кватерниона Y| `0`  |
| `z` |Векторная часть кватерниона Z| `0`  |
| `w` |Склярная часть кватерниона   | `1`  |

### `PSE.player:setDegree(pitch, yaw, roll)`

Удобный метод вращения игрока.

```lua
PSE.player:setDegree(0, 90, 0)
```

|Аргумент|Обозначение|Пример|
|--------|-----------|------|
|`pitch` | Наклон Y  | `0`  |
| `yaw`  | Наклон Z  | `90` |
| `roll` | Наклон X  | `0`  |

### `PSE.player:getDegree()`

Удобный метод получения вращения игрока.

```lua
local deg = PSE.player:getRotation() --- {pitch, yaw, roll}
```

| Поле  |Обозначение|Пример|
|-------|-----------|------|
|`pitch`| Наклон Y  | `0`  |
| `yaw` | Наклон Z  | `90` |
|`roll` | Наклон X  | `0`  |

## Существование

### `PSE.player:kill()`

Убивает игрока.

> [!WARNING]
> БАГ: в REPL вызывание данной команды превращает убийство в вечный цикл спавна и убийства игрока. В скрипте СРАЗУ после `kill()` используйте `setPosition()` (опоционально) и `spawn()`

```lua
PSE.player:kill()
```

### `PSE.player:spawn()`

Спавнит игрока.

```lua
PSE.player:spawn()
```

_* - Unreal Engine использует систему координат, в которой Z - является вертикальной координатой._
