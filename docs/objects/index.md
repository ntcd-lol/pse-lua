## Объекты

### Что это:

> Почти весь PSE SDK Lua базирован на объектах, и их легко создавать и получать о них информацию.

## Создание

Для сторонних объектов*:

```lua
local name = PSE.createObject()
    :commands()
    :create()
```
|Название|Обозначение|Пример|
|---|---|---|
|`name`|Название переменной, советуется уникальное чтобы делать код предсказумее.|`door`|
|`Object`|Название объекта*|`Door`|
|`commands`|Комманды вида цепочки Lua|`name`, `setPosition`|

## Получение данных

### GUID

```lua
name.guid
```

|Название|Обозначение|Пример|
|---|---|---|
|`name`|Название переменной, советуется уникальное чтобы делать код предсказумее.|`door`|

### CallBack ID

```lua
name.callbackid
```

|Название|Обозначение|Пример|
|---|---|---|
|`name`|Название переменной, советуется уникальное чтобы делать код предсказумее.|`door`|

### Transform

> [!IMPORTANT]
> Первый вариант будет отображать старые статичные значения, но быстрее, а так же в свою очередь если объект статичный - можно использовать его.

```lua
name.transform.location --- Позиция     | {x, y, z}
name.transform.quat     --- Кватернион  | {x, y, z, w}
name.transform.scale    --- Размеры     | {x, y, z}
```

|Название|Обозначение|Пример|
|---|---|---|
|`name`|Название переменной, советуется уникальное чтобы делать код предсказумее.|`door`|

Второй вариант (**рекомендауется**):

```lua
local transform = name:getTransform()
transform.location
transform.quat
transform.scale

--- Или просто:
name:getTransform().location
name:getTransform().quat
name:getTransform().scale
```

|Название|Обозначение|Пример|
|---|---|---|
|`name`|Название переменной, советуется уникальное чтобы делать код предсказумее.|`door`|

### State

> [!CAUTION]
> Никогда не используйте метод:

```lua
name._state
```

Это ВНУТРЕНЕЕ НЕОБНОВЛЕННОЕ значение, и если его использовать постоянно - ваш код банально не будет работать.

**Используйте:**
```lua
name:getState() --- Значение | 0 или 1.
```

|Название|Обозначение|Пример|
|---|---|---|
|`name`|Название переменной, советуется уникальное чтобы делать код предсказумее.|`door`|

### Присвоение объекта

> [!TIP]
> Особенно полезно, если объект инициализирован без переменной.

```lua
local name = PSE.get(guid)

--- ИЛИ
local name = PSE.get("object")
```

|Название|Обозначение|Пример|
|---|---|---|
|`name`|Название переменной, советуется уникальное чтобы делать код предсказумее.|`door`|
|`guid`|GUID объекта|`18446744073709551615`|
|`object`|Имя объекта|`Door_1`|
